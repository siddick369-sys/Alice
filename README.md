# Alice

Assistant vocal et visuel multimodal autonome (J.A.R.V.I.S / ALICE).

## Fonctionnalités principales
- **Interface 3D interactive** : Orbe Three.js réactive à l'état et à la voix.
- **Cerveau IA Hybride** : Google Gemini, Grok, Groq et fallback local 100% offline via Ollama.
- **Vision par ordinateur & Contrôle PC** : Tesseract OCR, capture d'écran, automatisation clavier/souris.
- **Domotique** : Intégration complète avec Home Assistant (lumières, prises, thermostat, scènes, alarmes).
- **Productivité & Google Workspace** : Google Docs, Sheets, Gmail, Google Calendar.
- **16 Modules Alice** : Génération d'images, transcription audio, RAG, analyse vidéo, détection d'humeur, etc.
